---
description: Точечный dart analyze одного файла (быстрая итерация)
---

Быстрая итерация: запусти `dart analyze <путь/к/файлу.dart>` из корня проекта (иначе false-ошибки про URI пакетов).

- Даёт результат за секунды, в отличие от полного `dart analyze lib test`.
- Используй её в цикле правок; полный `dart analyze lib test` — только в финале (см. `/verify`).
- Если ошибка ссылается на сгенерированный код (`.g.dart`) — прочитай нужный фрагмент `.g.dart` ПЕРЕД правкой, а не после ошибки компиляции.
